# Прототип: «Программа лояльности» в Мобильном менеджере

Макет для обсуждения с командой ММ, не рабочий экран. Открыт по ссылке, в поиск не попадает
(`noindex` в странице).

Исходник живёт в Life OS: `02-Работа/проекты/Мобильный менеджер/прототип/`.
Там правится `ММ-раздел-ПЛ-прототип.html`, скрипт `собрать-один-файл.py` собирает
`Прототип-ПЛ-в-ММ.html` (всё внутри одного файла), он копируется сюда как `index.html`
с мета-тегами превью.
